## FAQ

### Is OmniPatch safe to use?

OmniPatch is designed to run locally without collecting data. However, patching software may trigger anticomponent false positives. Users should disable anticomponent temporarily and understand the risks of modifying application files.

### Which AI applications are supported?

The tool currently supports patching and activating premium features for ChatGPT, Claude, Microsoft Copilot, Cursor, GitHub Copilot, Devin, JetBrains AI Assistant, and Perplexity. Support for more apps is planned.

### Does OmniPatch require an internet connection?

Initial patching requires internet connectivity to verify application versions. Once patched, many premium features can be used offline, but some cloud-based features may still require a connection.

### How frequently is OmniPatch updated?

Updates are released on a bi-weekly schedule or immediately when a supported application receives a major update that breaks functionality. Check the repository's releases for the latest version.

### Can I use OmniPatch on macOS or Linux?

No, OmniPatch is developed exclusively as a Windows desktop application (.exe) and is not compatible with macOS or Linux operating systems at this time.

### Will using OmniPatch affect my existing account data?

The patcher modifies the local application client, not your cloud account data or history. Your conversations, files, and settings remain intact.

### How do I revert the changes if needed?

OmniPatch creates a backup of original files in a 'backup' subfolder. You can run the included 'restore.exe' tool to revert applications to their unpatched state automatically.

### Is there a premium or paid version?

No, OmniPatch is and will remain completely free and open-source. Be wary of any websites claiming to sell licenses for it.
